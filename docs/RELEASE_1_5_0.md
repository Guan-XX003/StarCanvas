# StarCanvas 1.5.0

## 更新范围

- 独立桌面助手：移动、缩放、可选置顶、显示主窗口、收回画布。
- 共用加密会话与草稿，不另建画布、存储或模型请求控制器。
- 聊天 / 配置 API / 查错误导航、上下文角色与会话操作、统一字号和圆角。
- 本机头像、图片/视频/即梦/音乐/文本 API 引导、脱敏任务诊断草稿。
- 配套 CLI/MCP 1.5.0，现有 14 个工具和逐次授权模型保持不变。

## 验证

macOS arm64 与 Windows x64 均完成 1.4.9 → 1.5.0 的真实安装升级验证，
保留项目、手动 API 配置、原生安全存储、会话、草稿、角色及附件。
独立窗口的共享草稿、无父窗口约束、置顶、主窗口最小化/隐藏、关闭恢复、
带子窗口退出以及重启后草稿恢复均通过。配套 CLI/MCP 版本和 14 个工具已核对。

测试使用隔离数据和本地模拟服务，不包含真实付费生成验证。
API 引导只校验本地字段；实际协议、余额和模型能力仍由服务商决定。

本次回归包括窗口/关闭 22 项、工作台 77 项、界面辅助 12 项、权限 178 项、
打包底座 34 项，以及 456 项工具库用例。类型、版本一致性、架构和构建检查通过。
现有 GSAP 非模块、包体积和架构节点数量警告仍保留。
