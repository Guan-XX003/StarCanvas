then delegates to normal image/video hooks. Configured media type/count limits
are checked locally so the current sender does not silently drop inputs.

dispatcher then performs bounded read-only lookup in current configured groups,
rechecks config/project/session, and passes exact private asset metadata to the
normal root/factory. Guarded image nodes carry no preview URL; the normal manual
portrait collector, not a new sender, produces asset://ID references. Failed or
ambiguous lookup creates no nodes. Image nodes without previews render one
localized ID placeholder instead of overlapping empty/binding labels. Lookup
status does not guarantee future upstream availability; final sender-binding
timing and remaining specialized wire review still require audit.
